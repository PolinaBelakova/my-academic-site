## Что такое Git?
 
Git — это распределенная система контроля версий (Distributed Version Control System), созданная Линусом Торвальдсом в 2005 году для разработки ядра Linux. 
 
## Основные преимущества Git
 
- **Распределенность** — каждый разработчик имеет полную копию репозитория
- **Ветвление** — легкое создание и слияние веток
- **Производительность** — быстрые операции
- **Целостность** — все данные проверяются по контрольным суммам
