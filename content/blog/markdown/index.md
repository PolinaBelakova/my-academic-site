Markdown — это простой и удобный язык разметки, который позволяет форматировать текст, не отвлекаясь на сложные теги HTML. Он идеально подходит для создания контента для сайтов, блогов и документации.

## Основные элементы Markdown

**Заголовки** создаются с помощью решеток `#`. Количество решеток определяет уровень заголовка:
```markdown
# Заголовок 1
## Заголовок 2
### Заголовок 3
